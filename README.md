# NexusKeyGen
# 🔐 NEXUS KEYGEN  A cryptographically secure access key, token, and promo code generator built around a custom alphabet, supporting batch generation and key history.  ## ✨ Features  - **Signature Key Format** — generates keys like `K7M-HGTP-SVNM-BMZX-DKLJ-QW9R-FC48-PLVT-ZXMN-QW20`. - **Flexible Structure Customization:**   - Block count: `1` to `24`.   - Block length: `2` to `10` characters.   - Shortened first block option (3 characters).   - Custom separators: hyphen (`-`), underscore (`_`), or solid string. - **Custom Alphabet** — editable character set (defaults to consonants `H G T P S V N M B Z X D K L J Q W R F C`) with a toggle for digits. - **Batch Generation** — generate `1` to `20` unique keys in a single click and copy the entire list at once. - **Generation History** — automatically stores the last `30` keys with one-click clipboard copy.
